# 小兔与恐龙 · 喂食小游戏

适合 3 岁左右小朋友的手机网页小游戏：把胡萝卜喂给小白兔，把叶子喂给小恐龙。点一下或拖一拖就能玩，没有倒计时、没有惩罚。

## 在手机上打开

用手机浏览器打开（无需下载文件）：

https://jmjtjzy.github.io/bunny-dino-game/

建议竖屏全屏游玩。无广告、无登录。

## 怎么玩

1. 点「开始」。
2. 屏幕上会出现胡萝卜 🥕 或叶子 🍃。
3. 拖到对应的小兔 🐰 或恐龙 🦕，也可以直接点动物喂食。
4. 喂对了会弹跳、出小心心和温柔铃声；每成功几次还有小庆祝。
5. 想重来：双击右上角爱心分数，再点「再玩一次」。
